# Karimi jobs map

Public site at https://map.karimi.ai: open jobs on Karimi across Europe, by region (Eurostat NUTS-2).

Static files only, served by GitHub Pages:
- `index.html`: the page (d3 v7 from cdnjs, no build step)
- `data.json`: job counts per region, function, seniority and work type, plus region shapes
- `examples/<country>.json`: recent example jobs per region, loaded when a region is opened

Generated by `live_jobs_region_map.py` and `build_region_map_site.py` in karimi-stats. Don't edit these files by hand.

Serve locally with `python3 -m http.server` and open http://localhost:8000.
